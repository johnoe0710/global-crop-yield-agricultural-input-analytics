**How to capture a clean screenshot (not a development screenshot):**

1. In Power BI Desktop, switch to **Reading view** (View ribbon → Reading View), which hides the Visualizations, Fields, and Filters panes.
2. Widen the window or use a high resolution so text is legible at GitHub's display width (roughly 900–1000px wide reads well).
3. Use your OS screenshot tool to capture just the report canvas — not the Power BI title bar or Windows taskbar.
4. Save as PNG, using the exact filenames above.
