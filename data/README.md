# Data

## Status: raw source data excluded from this public repository

This project originally used a Kaggle-published dataset, but the exact listing, URL, and redistribution licence could not be independently confirmed. Because the licence was not confirmed, the raw source files are not included in the public repository.

The public release therefore contains the analytical method, supporting documentation, screenshots, and findings, but not the raw files or a downloadable Power BI file that would redistribute the underlying data.

## Public statement

> The raw source data for this project is excluded from the public repository because its redistribution licence could not be independently confirmed. The analytical findings, documentation, and screenshots remain available for review, but the underlying dataset is not redistributed here.

## Why the raw files are absent

- The underlying source files were not safely redistributable without confirmed permission.
- The Power BI report was not kept publicly downloadable because it may contain imported source copies.
- No claim is made that the source is open, MIT, CC BY, or otherwise redistributable.
